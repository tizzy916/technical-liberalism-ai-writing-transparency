## v6.0.2 · 2026-05-07 · 第 4 章 4.1.2 节阿伦特概念建构补强（部分 #10）

**类型**：修订执行（基于 Arendt perspective skill multi-perspective 自检后的针对性修订）
**触发**：v0.1 arendt-perspective skill 蒸馏完成后，对论文 4.1.2 节当前论证的镜片自检揭示了胡老师答辩质疑（action/work 滑动错位）的**更深一层错位**——论文当前把"创造性"挂在 work 端、"政治性"挂在 action 端，与 Arendt 自身的概念属性分配恰好相反（natality 即"开始的能力"才是真正的创造与开端）

### 5 处具体修订

**1. 删除"并非...而是"句式（首要错位）**
- **旧**：「与'技艺自由主义'最直接相关的并非通常被视为自由之巅峰的'行动'，而是常被忽视的'制作'」
- **新**：「'技艺自由主义'所关心的'做自由'同时调动 work 与 action 的不同维度」
- **理由**：原句把"做自由"挂靠 work 排除 action，是胡老师答辩质疑的直接靶子；改为"同时调动"是 lineage 投射的开始

**2. 修正属性分配（更深错位）**
- **旧**：「前者是技艺的、创造性的面向（造物），后者是政治的、公共性的面向（发起）」
- **新**：「前者提供做自由的**物质条件**（worldliness）...后者承担做自由的**开端能力**（natality + plurality）」
- **理由**：Arendt 自身的概念属性分配是 work = worldliness（不是 creativity）+ action = natality（即"开始的能力"，才是真正的"创造")。原句反向了，把日常用法"创造 = 制作"误植入 Arendt 框架

**3. 加 *HC* §31 反向警告 + 1972 Toronto 前置授权**
- **新增**：「阿伦特本人在《人的境况》第 31 节'用制作替代行动的传统'中明确警告：把 action 类比为 work...是西方政治哲学从柏拉图到马克思的根本错误(Arendt, 1958: 220-230)。但她在 1972 年 Toronto 研讨会上现场让步，承认三元区分是 *theoretical distinction*，三者在实际经验中是 *interpenetrated* 的(Hill, 1979: 317)」
- **理由**：先警告再让步——让 lineage 投射建立在 Arendt 本人 1972 现场授权 + 严格的 *HC* §31 边界双重锚点上

**4. 加 lineage 投射明确化（v0.5 Arendt skill 第 7 项诚实边界要求）**
- **新增**：「本文借用阿伦特概念时主要采纳 Honig（1993, 2017）的 reading 路线...这一选择是为了对接本文第 4.3 节的实践链条需要，并非阿伦特本人立场的直接搬运」
- **理由**：Honig 派的 work-action 边界 performative 重叠 reading 是论文 4.3 实践链条 ready-made 匹配 —— 但必须明确"派学者投射"边界

**5. 加 *HC* §23 艺术品论证补注 + Pitkin 1998 forward-link**
- **新增段 3**：把"艺术品 = work 最高产品"复杂化为"介于 work、thinking 与接近 action 的三向交叉"，本文只取 worldliness 维度
- **新增段 4 末**：「本文承认这一诊断对 animal laborans 的隐含贬低存在内在张力——Pitkin（1998）系统揭示阿伦特对劳动领域的鄙视掩盖了对女性家务劳动、再生产劳动等政治意义的盲点。本文第 4.5 节将正面处理这一限度」
- **理由**：避免论文继承 Arendt 的 animal laborans 鄙视，把"做自由"窄化为有闲暇与技术资本者特权
