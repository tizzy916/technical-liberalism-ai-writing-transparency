## 一、表层语言特征

### 1.1 人称习惯

- **第一人称"我"**：在表达学术判断、引入分析视角、与文献对话时使用
  - 例："**我**在这里将这三位思想家并置，不是为了构造一个概念上的对仗结构……"
  - 例："**在我看来**，朗西埃与斯蒂格勒之间的张力并非不可调和……"
- **本文**：在交代论证任务、章节安排时使用
  - 例："**本文**追问的是……"
  - 例："**本文**对上述理论资源的调用，并非在一个学术真空中展开。"
- **绝不可擅自替换**："我" → "笔者" 或 → "本文" 都是对作者声音的破坏

### 1.2 句式偏好

- **逗号流水句**：核心特征。一句话内可承载 3-5 个分句，用逗号串联推进
  - 例："这种异化的最终结果是，一种原本旨在颠覆现有权力结构、探索另类生活方式的解放性冲动，最终被窄化为一种在市场框架内的、以个人消费和创业为核心的、去政治化的个人主义。"
- **破折号插入**：用于在主句中嵌入定义、补充、强调
  - 例："这一思潮所许诺的'自由'日益被窄化为一种'消费自由'**——在技术资本预设的选项中进行选择的自由**。"
- **设问驱动**：用问句推动论证转折
  - 例："那么，在历史上是否存在过这样的实践？"
  - 例："但走出去之后呢？"

### 1.3 修辞偏好

- **"是对的，但..."结构**：先承认对方合法性再指出局限
  - 例："芒福德是对的：权威技术与民主技术的区分是理解我们时代技术困境的关键框架。但芒福德没有看到的是……"
- **"X 不是 A，而是 B"结构**：用于精确界定概念
  - 例："'技艺自由主义'**不是**与'技术自由主义'对立的另一种主义，**而是**技术自由主义的深化和完成。"
- **"X 既是 A，也是 B"双重性**：处理药理学式的辩证关系
- **概念中外文并置**："感性分配（distribution of the sensible）"、"技艺（technê）" — 关键概念首次出现保留原文

## 二、深层论证特征

### 2.1 论证节奏

**典型段落结构**："文献引入 → 概念整理 → 推进 → 锚定" 的螺旋
- 引入一个学者的概念（带页码引用）
- 用自己的话整理这个概念的关键点
- 指出这个概念的力量与局限
- 用"在我看来"句把整理推进到本文论证的下一步

### 2.2 学术姿态

- **对话性推进**，不是批判性继承：把朗西埃、斯蒂格勒、芒福德等都视为对话者而非批判靶标
- **承认局限再推进**：每次引入一个理论资源，都明确说"它不能解决什么"，再用下一个资源补缺口
- 这是论文最有特色的姿态——它把学术对话写成了真正的对话，而不是单方面的应用或批判

### 2.3 引用的修辞功能

- **理论支援型**（绝大多数）：引入概念→为本文论证服务
- **历史史料型**：芒福德/特纳/巴布鲁克等的历史叙述
- **对话接口型**：许煜的 cosmotechnics（导言专段处理）
- **不喜欢**：堆砌式引用、为博学而引用

### 2.4 章节衔接

- 每章开头通常引用上一章的结论 + 一句"那么……？"的设问 + 本章任务说明
- 每章结尾通常一段总结 + 引向下一章的问题
- 这种"问题接力"是论文论证累积性的关键载体，**不可破坏**

## 三、概念译名规范

| 外文 | 中文 | 备注 |
|---|---|---|
| technê / Technê | 技艺 / technê | 概念性场合保留原文（如"technê 的整体性"） |
| technolibertarianism | 技术自由主义 | 全文统一 |
| Technê-Libertarianism | 技艺自由主义 | **官方译名**，全文统一（**禁用** techno-artisanalism） |
| distribution of the sensible | 感性分配 | 朗西埃 |
| pharmakon | 药剂 / pharmakon | 古希腊语，同时意味着"药"和"毒"。德里达《柏拉图的药》以来确立的本体论概念，斯蒂格勒承袭。**核心立场**：不是"两类东西"（一类毒一类药），而是**同一物的两种运作状态**。可保留原文不译，或译为"药剂" |
| poison / 毒药 | 毒药 | pharmakon 的毒性运作状态 |
| remedy / 解药 | 解药 | pharmakon 的治疗性运作状态。**用法**：第 3 章具体艺术案例分析（白南准段已用）+ 导言论证地图段（#02）+ 第 4 章规范性建构（联动）。**禁用**："反向药剂"（生造词）、"反药"（含义模糊）|
| 解放性药剂 | 解放性药剂 | "解药"在第 3 章具体艺术案例中的具体化命名（如 3.4 节标题）。是"解药"的同义具体化，不是另一概念 |
| pharmacology | 药理学 | 斯蒂格勒晚期方法论 |
| critical pharmacology | 批判药理学 | 斯蒂格勒方法论命名，对应本文论证结构的方法论锚点 |
| thérapeutique | 治疗法 | 法语，指 pharmakon 的具体使用方式与社会装置——决定 pharmakon 是发挥毒性还是治疗性的关键 |
| Gestell | 座架 | 海德格尔，孙周兴译法 |
| Bestand | 持存物 | 海德格尔 |
| megamachine | 巨型机器 | 芒福德 |
| megatechnic bribe | 巨型技术贿赂 | 芒福德 |
| savoir théorique / savoir-faire / savoir-vivre | 理论知识 / 实践技能 / 共同生活之道 | 三联体首次出现一并标注 |

### 行内引用人名规范

- 西文作者首次出现：中文译名 + 原文 + 生卒（如适用）
  - 例：雅克·朗西埃（Jacques Rancière）
- 后续：可只用中文姓（朗西埃）
- **行内引用统一用英文原姓 + 年份**：(Rancière, 2004) 而非 (朗西埃, 2004)
- 引用中文译本时例外：(芒福德, 2015b)、(阿伦特, 2009)

## 四、避免的表达模式（AI 痕迹 + 八股 + 未审视惯性）

> 以下是必须排查并替换的表达模式。基于答辩评议反馈和 AI 痕迹清单。

| 类型 | 示例（要排查） | 替换原则 |
|---|---|---|
| 学术八股套话 | "值得注意的是"、"不难发现"、"诚然……但是" | 用作者的具体判断替代 |
| 空泛断言 | "唯一希望所在"、"本质上是"、"决定性的" | 弱化或加上具体支撑 |
| 填补空白式表述 | "本文填补了 XX 领域的空白" | 改为"本文提供了一种新的视角""本文揭示了一个被忽视的面向" |
| 过度排比对仗 | 三段式排比 + 工整句式 | 让排比自然生长，不要强求对仗 |
| 过度过渡词 | "此外"、"同时"、"另外"密集出现 | 大部分可以删 |
| 把"我"改成"笔者"/"本文"/被动语态 | （任何把作者第一人称客观化的修改）| 一律恢复"我" |
| 逻辑过度填充 | 把作者有意的跳跃和留白补上过渡句 | 信任作者的论证节奏 |
| **破折号过度使用** | 一段内 ≥3 处双破折号"——"，特别是"X——Y——Z"双重插入或"标题——解释"机械化模板 | 见下方"破折号使用规则" |

### 破折号使用规则（2026-05-04 新增）

**问题诊断**：作者本身偏好破折号插入（见 1.2 节），但 AI 写作会把这一偏好机械化，每隔一两句就插入一个破折号，呈现典型 AI 签名。需要区分"作者真实节奏"vs"AI 模仿失败"。

**密度判断标准**：

| 类型 | 真实作者风格 | AI 痕迹 |
|---|---|---|
| 叙事性章节 | 每 200-400 字 1 处破折号 | 每 50-80 字 1 处 |
| 理论分析章节 | 每 300-500 字 1 处 | 每 50-100 字 1 处 |
| 结构性 / 说明性段落（如导言论证地图段）| 0-1 处 | 5-10 处 |

**用什么替代过度破折号**：

| 原破折号用法 | AI 模板 | 改为 |
|---|---|---|
| 标题分隔符（"**第 X 层是 Y**——展开"）| 高频出现 | 改为冒号"："（更接近作者偏好的标题处理方式）|
| "X——Y"（解释、转折） | 高频 | 视语义改为：冒号"X：Y" / 句号"X。Y" / 逗号+连接词"X，因为 Y" |
| "X——Y——Z"（双破折号插入） | 几乎都是 AI 痕迹 | 把 Y 拆为独立句，或用括号"(Y)" |
| 强调性停顿 | 偶尔一处可保留 | 真正有停顿需求时保留，但每段控制在 0-1 处 |

**真正有破折号需求的位置**：
- 引出一个有强烈停顿感的限定或补充
- 作者刻意强调的转折
- 引文之间的衔接

**写作时的检查问题**：写完一段后，数一下双破折号"——"的数量。超过 2 处就要审视：是真正需要的停顿，还是 AI 模板的机械产物？

## 五、本次修订的特殊约定（v6.0）

基于张黎、邓碧文两位评审反馈，本轮修订的特殊原则：

1. **题目不改**：保留《20 世纪 60 年代审美革命中的技术自由主义》（作者明确决定）
2. **概念建构延后**：导言里"技艺自由主义"只做"概念预告"，详细建构延后到第 4 章
3. **理论与案例的张力要透出来**：第 3 章不要让斯蒂格勒框架"覆盖"案例
4. **第 5 章诚实化**：AI 辅助写作那节要写出失败/被同化的维度
5. **结尾要具体**：未完成的回归 = 三条具体的后续工作
6. **血缘显形原则**（2026-05-04 新增）：本文每一个原创性命名、概念组合、方法论框架，**都必须在论文中明确显示其学术血缘**——它承袭自哪条传统、由哪些学者提供概念资源、本文做的具体动作是什么。这一原则的目的是把"想象力"的性质从"修辞性"（贬义：作者凭空生造）转化为"论证性"（褒义：作者综合学术传统做出新的接合）。
   - 应用到 #02：症候/诊断/反向药剂三分框架 → 显示为福柯"对当下的诊断" + 斯蒂格勒"批判药理学"传统的具体应用
   - 应用到 #04：技艺自由主义命名 → 显示为亚里士多德-海德格尔-斯蒂格勒-许煜的 technê 概念史脉络的端点
   - 应用到 #05：三个创新点 → 各自显示其建基于的学术传统
   - 应用到 #10：第 4 章 4.1.2 概念建构 → 阿伦特/海德格尔/斯蒂格勒"差异性结合"的具体血缘
   - **写作时的检查问题**：每当写下一个看似原创的命名或框架，问自己——这个东西的学术血缘在哪里？如果说不上来，要么补上引用，要么改用已有的概念。

## 六、持续学习记录

> 修订过程中发现的新风格特征或偏好变化，记录于此。

- [2026-05-03 启动] 档案首版建立，基于 v5.0.2 全文阅读和两份答辩评议
- [2026-05-04 演化] 在 #02 论证地图段精修过程中，作者明确表达：
  1. 警惕修辞性想象力（贬义）—— 担心论证框架被读为"作者富有想象力（贬义）"
  2. 学术血缘必须显形 —— 每一个原创操作都要展示其传承
  3. 这条原则被记录为"血缘显形原则"（见第五节第 6 条），并联动到 #04、#05、#06 档案
  4. 此演化反映出作者的学术姿态：原创性的合法性来自学术传承的可见性，而非"个人天才"的展示。这一姿态本身也是论文核心命题（"做自由"作为持续判断练习而非一次性原创）在写作层面的实践

- [2026-05-04 演化] 在 #02 #06 草稿打磨过程中，作者明确指出 AI 写作的破折号过度使用问题：
  1. 一段内 23 处破折号呈现典型 AI 写作签名
  2. 即使作者本人偏好破折号，密度也应在每 200-400 字 1 处的自然节奏，而非每 50-80 字
  3. 这条诊断被记录为"破折号使用规则"（见第四节"避免的表达模式"扩展），作为新增的 AI 痕迹排查项
  4. 关键启示：作者的写作偏好被 AI 模仿时，常常会被机械化、密度化，反而成为 AI 痕迹的重灾区。后续修改要警惕"作者偏好"被过度复制成"AI 模板"

- [2026-05-07 演化 · v6.0.4 修订后] 作者对 v6.0.4 #10 修订执行了术语替换：
  1. **performativity 译名**：AI 草稿用"表演性"，作者改为"述行性"
  2. 学术理由："表演性"是通俗译，易引起"作秀"误读；"述行性"是中文学界（巴特勒译介脉络）确立的学术译名
  3. 译名规范表已更新（见第三节）；后续涉及 Butler / Honig 派 performativity 概念时统一用"述行性"
  4. 关键启示：作者对学术译名有精确判断，AI 默认用通俗译时应主动查证中文学界共识译名 — 不只是"译对"，还要"译入学术传统"
