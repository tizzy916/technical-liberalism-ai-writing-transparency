# 技术自由主义论文与 AI 写作过程公开包

本仓库用于公开展示《20 世纪 60 年代审美革命中的技术自由主义》的论文源稿、AI 辅助写作过程记录、版本修订日志与引文核查材料。

公开目的不是把 AI 包装成“代写者”，而是相反：把 AI 在写作中的介入位置、失败记录、修正机制和最终责任边界暴露出来，让读者能够检查这篇论文如何在 AI 协作条件下保持作者判断、引用责任和写作声音。

## 公开包处理原则

本公开包不是原始 Obsidian 项目目录的无差别镜像。为降低公开风险，我做了以下处理：

- 未包含第三方 PDF、EPUB、书籍全文、论文全文附件。
- 未包含历史 Word/PPT 导出、旧版本二进制文件、`.DS_Store`、缓存、锁文件和系统残留。
- 未包含原始会议转录等可能涉及他人未授权表达的材料。
- 保留 Markdown 源稿、过程日志、引用核查报告和可审计的修改说明。
- 对公开副本中的已知 AI 幻觉引用做了最小修正，详见 `PUBLICATION_COMPLIANCE_REPORT.md`。

## AI 使用声明

AI 参与了文献检索、结构审读、句子修改建议、引用风险提示、版本整理和公开包准备。核心论点、最终判断、修订取舍和公开责任由作者承担。仓库中特意保留了 AI 写作失败、引用幻觉和风格异化的记录，因为这些失败本身正是本项目想公开的内容。
